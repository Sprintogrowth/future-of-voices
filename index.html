We inform you that this website, operated by BRIANYADS US LLC, uses cookies.

Cookies are small text files sent to a browser from a web server to record a user's activity on a website, so that this information can be retrieved later while browsing other pages connected to the server that installed them.

Cookies typically store technical information, personal preferences, content personalization, usage statistics, links to social networks, access to user accounts, and similar data.

Types of Cookies

Below is a classification of cookies based on several categories. Note that a single cookie may fall into more than one category.

By the entity that manages them

  • First-party cookies: sent to the user's device from a computer or domain managed by the website owner itself, which provides the requested service.
  • Third-party cookies: sent to the user's device from a computer or domain not managed by the website owner, but by another entity that processes the data collected through the cookies.

By the length of time they remain active

  • Session cookies: collect and store data only while the user is accessing a web page.
  • Persistent cookies: data remains stored on the device for a defined period, from a few minutes to several years.

By purpose

  • Technical cookies: allow basic browsing and core functionality.
  • Personalization cookies: remember general preferences such as language or region.
  • Analytics cookies: measure activity and build browsing profiles to improve the service.
  • Advertising cookies: manage advertising space based on edited content.
  • Behavioral advertising cookies: build a profile from browsing habits to show relevant ads.

How to Disable Cookies in Major Browsers

To configure cookie settings, follow the instructions for your browser or consult its help section: Safari, Firefox, Chrome, Opera, Internet Explorer, Edge.

What Happens If You Don't Accept Cookies
